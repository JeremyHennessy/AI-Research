Use the same sensing channels, action consequences, code formation, RAM, instruction costs, energy caps and termination rules. Register comparator code and contexts before execution. No free host-side learning updates.

The proposed scaffold's conditional worst-case ordinary nonlearning acquisition uses 13 instructions plus a 4-energy failed-action penalty, versus a 20-energy acquisition; a good first prediction uses 6 instructions. These are design calculations, not a complete survival certificate. Formation is 76, startup 12 and the cold prefix ends at energy 23 in the disclosed prepared route. Independently derive every startup/release, retry, branch, read/write and cap-loss charge from actual histories.

A useful feasibility result requires complete paid trajectories across the registered contexts, informative personal observations and causally useful retained knowledge. A positive benchmark cannot confer intelligence credit on blind candidates. Failure identifies affordability, information or mechanism issues without lowering closed costs.

## Passive diagnosis from existing evidence

For each candidate and context, retain these separate quantities:

| Question | Recorded measurement |
|---|---|
| Did it receive usable information? | Distinct actual packet/action feedback origins, visible context and outcome |
| Did it preserve context? | Register values and context identity across prediction, feedback and update |
| Did it use memory? | Actual read/write addresses, prior values, written values and causal origin |
| Did experience change decisions? | First action on a new return packet compared with matched controls |
| Was improvement useful? | Paid score, completion, energy gained after cap losses and deaths |
| Was the comparison exposed fairly? | Common actual packets and missing-control decisions, separately counted |

Diagnostics are read-only interpretations, never organism inputs or hidden rewards. Keep PC and latch effects visible; a stored bit alone is not learning. Use actual common packet opportunities for conditional accuracy. Missing control responses remain in unconditional cost/death/completion denominators and cannot be scored as wrong guesses. Retrospective patterns generate hypotheses, not new acceptance thresholds.
