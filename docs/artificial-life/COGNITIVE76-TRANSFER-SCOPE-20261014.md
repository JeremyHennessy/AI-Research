# Pass B: distinguish new instances, adaptation and transfer

October 14, 2026. Future experimental options only; Cognitive76 criteria and current run remain unchanged.

## Primary research
[CoinRun, Cobbe et al. 2019](https://proceedings.mlr.press/v97/cobbe19a.html) evaluates overfitting using separate procedurally generated training and test environments. It finds that agents can overfit large training sets. That result motivates distinct evaluation samples, not adoption of neural networks, image inputs or its reward rules into Ora.

[CORA, Powers et al. 2022](https://proceedings.mlr.press/v199/powers22b.html) separates continual evaluation, isolated forgetting and zero-shot forward transfer. Its benchmark platform is a measurement reference, not evidence that Ora learns or needs those large environments.

## Ora-specific distinctions
| Proposed comparison | Narrow question |
|---|---|
| Fresh cue/packet orders, same two-bit task | Does useful behavior repeat on new instances? |
| Hidden mapping changed after personal learning, no-change control | Can the same entity revise acquired knowledge? |
| Revisit an unchanged context after learning another | Does learning one context damage retained knowledge? |
| New cue encoding or action relationship, separately specified | Is there transfer beyond the original task family? |

Current Cognitive76 unseen contexts repeat the four possible hidden maps with fresh ordering. A positive supports that declared instance scope, not unlimited task generalization. The finite two-cue model cannot prove broad intelligence.

## Smallest later extension
After the current result, choose ONE relevant axis, not a suite that changes all of them. Freeze source enrollment, hidden task schedule, paid budget, causal controls and stopping criteria before fresh samples. Use the same source in changed and no-change conditions; the entity receives no change label or researcher memory repair.

Measure paid first-choice benefit and completion, before/after adaptation, and performance on unaffected contexts. For forgetting, retain the original knowledge and return opportunities; do not reset memory between tasks. For zero-shot transfer, measure before new-task feedback separately from later relearning.

Preserve exploration costs and unconditional deaths. Common actual opportunities determine conditional accuracy; absence stays an explicit denominator gap. Do not select the historical winner for confirmation, repeatedly inspect test outcomes to choose endpoints or alter the closed horizon. All apparatus assistance must be disclosed.

## Practical handoff
Complete the current experiment before extending it. Reuse source/hash-qualified VM, control and custody components; implement only the selected prospective task delta and independent evaluator parity. An exploratory diagnostic can guide a later fresh confirmation but cannot confirm itself.
