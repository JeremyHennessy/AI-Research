## What is already established, and what is not

1. **Basic exploration is no longer the missing mechanism.** In Exploration13 the supplied feedback-ignoring four-triple alternator attempts both ports, succeeds in both initial orientations, collects all 32 local packets including 16 released packets per history, and later dies. It has zero FEEDBACK reads, memory operations and births. This is paid *fixed exploration*, **not** learned change. Its success does not repair Experience12: all four original feedback fixtures still die from wrong-port initial lock-in in the opposite orientation, before tick 64.
2. **The existing richer information law is not a demonstrated noisy generalization case.** For the 16 post-64 local released packets in Exposure23, the hidden target is the seed-orientation bit XOR a paired hidden latent bit XOR a deterministic per-packet exception whose hash residue must equal zero modulo 16. That last condition has a nominal **1/16 hash threshold**, *not* a measured independent Bernoulli noise process. The only published Exposure23 software seed pair had latent-flip zero and **zero exceptions**; it did not actually expose the ability to resist an exceptional observation. The reactive witness completed food but failed the pre-boundary both-outcome gate in one orientation. This closed refusal is a comparator-criterion mismatch, not learning failure or grounds to retune the gate.
3. **History tags are not demonstrated useful learning.** The sealed History50 census reported 11/256 originally neutral programs with a retained earlier-feedback effect and 2 cells overlapping earlier apparent work/latency gains, but **zero** passed the intact complete fixed-reference gate. The 256 programs were born from one approved performance-blind source, not 256 independent origins. The source's 1..8/18 opcode alphabet excludes MOVE and SENSE; their code cannot be silently extended and called the same sampled cohort.
4. **Feedback machinery can erase its own payoff.** The closed Capacity60 authored intact control saves 30 ACT/CONST instructions relative to fixed exploration per paired comparison but spends 28, 35 or 42 extra control/feedback instructions. Its measured net instruction differences are -2, +5 or +12 for those groups, and intact wins only 2/4 primary and 2/4 unseen pairs. These are actual closed bills, not evidence for a successful learner, and cannot become a universal threshold for different programs.

## Exactly one new research decision: require a distinguishable, affordable information opportunity

**Do not commission another within-life learning candidate cohort until a predeclared ordinary route has a *decision-relevant older-history opportunity* under the already installed law and fully paid resource scheduler.** In the same context, the actual intervention arms must share the pre-intervention environment and reachable resource opportunities; the candidate may not be rescued, rewritten or selected after viewing outcomes.

For the specific *older-history beyond latest feedback* hypothesis, first show an analytically possible pair of **prospectively declared hidden-resource contexts** with the same information available to an appropriately clock-/state-matched latest-feedback/reactive reference at the later choice (including cue, position and most recent latch), but different useful actions. Their earlier **truthful personal observations**, if retained, must contain information that distinguishes the contexts. The contrasting hidden contexts may differ between paired settings; within *each* setting, control and intact experience the same exogenous resource stock, release schedule, initial orientation and target function. Do not match controls by forcing equal action outcomes, or rely on a hindsight oracle knowing the target. If no such reachable contrast is identified, *older-history usefulness is untestable by that proposed exposure*; this is an assay rejection, not proof that artificial digital learning is impossible.

The VM gives an exact illustrative memory-mediated causal path, rather than a constructed successful policy:

- `ACT` produces a genuine same-actor feedback outcome, charged one instruction. A FEEDBACK opcode (`1`) moves the truthful latch into a register, charged one instruction.
- `WRITE` opcode `3` copies that register into one of eight four-bit memory words, charged one instruction.
- A **distinct intervening real resource ACT** changes the latest latch. Later `READ` opcode `2` retrieves the older stored bit to a register, followed by an actual charged port-choice `ACT`. This literal six-event route has **at least six charged instructions**: ACT, FEEDBACK, WRITE, intervening ACT, READ, later ACT. This is a lower bound for this *illustrative route*, **not** a general minimum for all history-carrying architectures or six additional instructions relative to any control. Program branches, code formation, cold exploration, failed/empty attempts, cap losses and every real action add charges.
- Formation remains `3 × program triples + 16` energy/material; founder startup is 12, instruction cost is 1, cap is 64, each successful packet offers at most 20 before overflow; 16 newly accessible home packets require the unchanged tick-64 exogenous release costing 16 constructor energy, not free actor energy. The finite endpoint is tick 512 or extinction. A memory-containing program that dies before its informative contrast or cannot afford its subsequent action is **not admitted** merely because these opcodes exist.

Program-counter, registers, latest latch, RAM, and any actually accessed code, message/inbox or position channels can preserve information. A RAM-only reset does not establish history-disabled equivalence. Record actor/source of every observation, actual writes/reads, intervening action and first later useful-action divergence. Foreign inherited information is not same-life learning. Prepared kernel provenance tags cannot supply the missing counterfactual. Independently reconstruct the full cost from the actual VM, retain **all** failures, and compare the same organism's outcomes against fixed-reactive, memory-disabled and own-history-disrupted **actual-channel** controls on genuinely held-out conditions. Require useful food/energy/survival outcomes rather than opcode counts, origin labels or code-installed memory alone.
