## Main finding: learning inside a graph versus learning its structure

Rosenbloom, Demski and Ustun, [Sigma, 2016](https://doi.org/10.1515/jagi-2016-0001), [publisher PDF](https://reference-global.com/download/article/10.1515/jagi-2016-0001.pdf), JAGI 7(1), 1–103. First page visually verified; CC BY 3.0. Selected sections 4.2.4, 6.2, 7 and 8.1 read as indexed text; page 91 image returned unsupported content type. This article describes how a common gradient-based algorithm can support diverse learned functions within a provided graph. Section 8.1 explicitly identifies the absence of learning that adds or changes graph nodes and links, as of that publication; motivation, bodily state and motor control also had important gaps. Section 7 reports approximately 250 ms cognitive cycles versus a 50 ms target, with faster activities handled by external SmartBody algorithms. This is an important scaffold and resource-accounting comparator, not a claim about later Sigma versions, and not a full E2 audit.

Ora interpretation: a system that learns values inside an authored computational structure has not necessarily developed the structure itself. A learned change to structure likewise does not by itself establish inheritance or survival advantage. Separate externally executed helper work from internal resource accounting.
