## Most useful negative evidence

[Anderson et al., 2008, Using fMRI to test models of complex cognition](https://pubmed.ncbi.nlm.nih.gov/21585456/), DOI 10.1080/03640210802451588, reports a deliberate attempt to test six ACT-R module-to-brain mappings with time-aligned human imaging. Three predictions were supported in the selected task (visual encoding, retrieval, subgoal setting); three missed observed features (motor anticipation, parietal activity, initial caudate response). This is author-abstract evidence (E1), not a count of modules generally validated or disproven. It is a particularly useful comparator for component-level falsification: overall task success cannot validate every claimed mechanism.

[Anderson et al., 2012](https://pubmed.ncbi.nlm.nih.gov/22209783/) report >80% path inference accuracy in a 625-state, 24-operator human problem-solving task using a supplied transition model, behavior timing and imaging. This is externally inferred latent state, not evidence of an agent generating its own representations. [Anderson and Douglass, 2001](https://pubmed.ncbi.nlm.nih.gov/11713870/) report that retention interval affected goal retrieval time rather than storage time in a modified Tower of Hanoi task, with an ACT-R simulation. Time cost in a human task is not metabolic expenditure. [Anderson and Betz, 2001](https://pubmed.ncbi.nlm.nih.gov/11848582/) combine authored exemplar and rule strategies; selecting between supplied strategies is not independently inventing a learning mechanism.

Ora prior-art interpretation: distinguish observing behavior, inferring internal state, intervening on a specific mechanism, and demonstrating a net reproductive benefit. Preserve component-level negative evidence even when aggregate performance is good. None of these papers establishes spontaneous organism-level cognition or authorizes Ora execution.
