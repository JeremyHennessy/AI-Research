## Substantive prior-art finding: interpreting an unexpected event is not just reacting to it

Firby and Slack's [1995 original report](https://cdn.aaai.org/Symposia/Spring/1995/SS-95-02/SS95-02-012.pdf), sections 3.2–4.3, describes an implemented robot using designer-defined conditional memory updates, environmental propositions and reactive actions. Page 109 (PDF index 12) visually confirms that the scheme has no appropriate interpretation rule for a completely unanticipated event if no applicable task context exists. Predefined monitors handle some otherwise unexpected events, but the paper recognizes the conceptual difference between anticipation and a genuinely unexpected event. This is a valuable negative control for interpretation of apparent learning. A system can update the world-state representation or respond flexibly while all possible interpretation rules remain authored. It does not establish that no other mechanism could acquire new interpretations. The paper's simple hallway demonstration is not a test of open-ended cognition. E1 selected methods review, not full audit.

The [1997 shuttle tracking report](https://cdn.aaai.org/IAAI/1997/IAAI97-193.pdf) first page describes preliminary successful procedure tracking despite intermittent missing telemetry and unexpected crew behavior; the system tracked externally provided procedures rather than learning flight control. The [1998 NASA workshop report](https://cdn.aaai.org/Workshops/1998/WS-98-02/WS98-02-014.pdf) printed page 90, visually verified, reports use of 3T to control gas transfers during a 90-day crewed life-support test beginning in September 1997. Upper-level human coordination and scheduling limitations are acknowledged. Do not equate this with the separate later 16-month water-recovery deployment, with autonomous survival, or with resource self-production. These 3T records share a research lineage and are not independent demonstrations of general intelligence.
