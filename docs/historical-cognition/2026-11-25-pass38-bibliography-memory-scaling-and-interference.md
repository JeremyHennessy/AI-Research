## Scientific crosswalk
The AFRL 2009 paper's first page identifies external database access and a planned 10–15 thousand word/multiword vocabulary for a domain-specific synthetic teammate. The project involved AFRL with CERI, AGS TechNet and L3 Communications. This is a documented government/private institutional collaboration, not an award-output match or a demonstration of the projected vocabulary or completed teammate. The 2010 follow-up explicitly changes retrieval implementation; distinguish supplied storage, imported content, retrieval efficiency and learned content. The 2010 Soar work is a separate architecture and comparator, not an ACT-R experiment solely because of upstream classification. No operational or military application assessment undertaken.

The Elliott/Anderson human experiments motivate a tradeoff between obsolete memories and valuable old observations under changing environments. The Drewitz/Brandenburg human experiment motivates testing whether invalidation generalizes beyond the specific association. These are candidate controls for future research interpretation, not evidence of Ora memory or recommendations to execute experiments. A manually reduced capacity can resemble childhood performance (Jones/Ritter), but does not explain how the capacity develops. Keep resource state, storage availability, memory acquisition, retrieval policy and evolutionary benefit distinct.
