## Main-text E2 review

- Physical substrate: fabricated Ag2Se nanowire network on a 16-electrode array. Investigator-specified digit voltage streams, sample boundaries, signal acquisition, normalization, per-instance phase alignment by correlation with original input (eqs. 1–2), and external linear supervised readout (eqs. 3–8). Feature columns and labels shuffled for training. Online weight updates are not equivalent to autonomous physical learning in real acquisition order. Alignment uses input information; the boundary of whole-instance processing matters for any real-time claim. Initialization uses a feature statistic; whether it was estimated prospectively needs code inspection. No claim of leakage established.
- Classification: Table 1 compares external RLS-style training (one pass over 50,000 samples) against gradient-based batch training (100 epochs), both on reservoir features; 10,000 test samples, five iterations. One/five channel online accuracies 91.6/93.4%, batch 86.6/91.4%. Thus improvements of 5.0/2.0 percentage points compare training algorithms, not isolated physical memory effects. Authors report comparable accuracy without active error correction. Five shuffled iterations are not five independently fabricated devices. No matched raw-input classifier or independent device replication identified in the main table.
- Information analysis: class-label mutual information estimated externally with JIDT/Kraskov at individual pixel positions, then aggregated; Fig. 5 class-dependent associations are descriptive. Neither sum of marginal mutual informations nor an external label predictor proves internal use of information or an increase in total information relative to complete input history.
- Sequence reconstruction: fixed repeating eight-class pattern 14751479, images sampled within each class; 7,000 training and 500 test windows, L=2–8. External supervised linear reconstruction and SSIM, not prospective decision or independent formation of a memory policy. Fig. 8 reports greater reconstruction quality with conductance features; replacing columns with scaled voltage features from another electrode lowers quality. This is a useful feature-level comparison, not a selective physical reset or proof that all difference arises from memory alone. Channel change can also change other feature properties. No novel sequence-order generalization demonstrated in main experiment. Window overlap/split policy and whether test maxima were chosen retrospectively remain code-audit questions, not established faults.

## Original analytical check — predictable context can mimic recall

Let T be the target digit class at a uniform random phase of the cyclic pattern 14751479 and C_k the next k classes. Assume an ideal observer sees those classes perfectly but has NO access to past inputs, phase labels or retained physical state. For k=3 the only context shared by different target classes is 147, preceded by either 5 or 9. The six remaining phase positions have unambiguous target classes (475, 751, 514, 479, 791, 914). Consequently a context-only optimal classifier has accuracy 7/8 and H(T|C_3)=1/4 bit; for k=4 every phase context identifies its target class, so accuracy is 1 and H(T|C_4)=0. This corresponds to the paper's L=4 and L=5 windows and is consistent with the authors' contextual explanation of the improvement for digit 9. It is a mathematical class-level counterexample, NOT a measured SSIM baseline, reconstruction of unique handwritten images, or refutation of physical memory. The class prior can supply information while individual image details still require additional evidence. A future authorized evaluation should use matched subsequent cues, unpredictable target identities, held-out sequence orders and selective history controls; record actual organism action and cost separately from an observer's decoding accuracy.
