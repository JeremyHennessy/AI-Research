## Original analytical crosswalk — fairness is not adaptive priority
Consider two eligible threads A and B on a nonpreemptive single processor, each requiring one time unit, both ready at t=0. A was served less recently and has no deadline; B must finish by t=1. Least-recently-served chooses A first, so B finishes at t=2 and misses its deadline. Serving B then A meets both requirements. This is a counterexample to equating fair arbitration with deadline-optimal scheduling, not a claim about the historical model's observed failures or a new scheduling theorem. The assumed urgency information is external in this example. A future separately authorized Ora evaluation should separate authored dispatch policy, acquired task urgency, actual resource occupancy, response latency, and functional payoff, with matched resources and a fixed-policy comparator. An apparent improvement could arise from supplied priority, reduced workload, or learned coordination; distinguish these explanations before claiming an acquired capability.
