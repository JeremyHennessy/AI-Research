## Ora prior-art crosswalk
Forgetting is not uniformly beneficial: under a simple hypothetical two-location resource task, if the formerly productive location A becomes depleted while B becomes productive, a memory retaining only the newest accurate observation can outperform one using an unweighted historical majority. Conversely, if a rare but still valid hazard is forgotten, the same recency preference can increase risk. The useful property is context-dependent retention/update, not maximum forgetting. Distinguish fixed decay, acquired control of retention, current-state prediction, and causal inference; evaluate stale-state errors, delayed returns and retention costs separately in any future authorized experiment. These are analytical examples, not Ora observations or novelty claims. The historical study used supplied heuristics; no evolution of a new memory architecture established.
