## Ora crosswalk
Environmental access is not itself acquired perception: a pixel interface can still emit designer-selected object labels and task-specific features. Two agents may produce identical visible decisions while one retrieves a stored example and the other applies a transferable rule; equal observed accuracy therefore cannot distinguish these mechanisms. Later separately authorized assessment could distinguish supplied observation transformations, state-dependent action selection, retained examples and generalizable rules by testing withheld combinations and documenting information provenance. This is an evidence distinction, not a proposal to change the current runtime. Human imaging and model fits do not establish the same mechanism in Ora or novelty.
