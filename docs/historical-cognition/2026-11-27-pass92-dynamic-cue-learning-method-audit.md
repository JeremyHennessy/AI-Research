## Original analytical crosswalk
Metric selection changes the comparative conclusion: better global agreement need not imply better tracking of local changes. A stationary-offset comparator can fit absolute levels while missing reversals, whereas a biased adaptive comparator can track changes while missing absolute values. For Ora, future scientific review could distinguish baseline error, change-direction accuracy, response delay, stability under no change, and resource/reproductive consequences; these are conceptual distinctions only, not an authorized protocol or evidence of cognition. An explicit neutral option matters because choosing against a cue is still using that cue. Historical priors and alternatives were supplied; no emergent mechanism or novelty claim.
