## Original analytical crosswalk
For a fixed selected memory with activation A, a latency function T=I+F exp(-fA) has identical output for two cues with the same A, whatever common constants I,F,f are chosen. Thus tuning these constants alone cannot explain a systematic contrast between those cues. The conditional invariance is algebraic, not a reproduction of the historical simulations. In an Ora-relevant evaluation, adding irrelevant associations while preserving task-relevant evidence could distinguish competing accounts of retrieval; a model that merely fits aggregate performance may fail this contrast. This is research reasoning only, not an experimental request, design change or new evidence of Ora cognition.
