## Original Ora evidence crosswalk
Retaining cases, generalizing over designer-selected features, and inventing a representation are three different achievements. For example, a history of two encounters that produce the same outcome may support a common category, but a system supplied the category in advance need only retrieve it. Likewise, a user choosing which suggested associations to save supplies a supervision signal. No observation in the owner-reported reproductive inheritance campaign establishes any of these learning mechanisms, and an archive analyst's own grouping of traces is not evidence that an organism created those groups. This is an interpretive boundary, not a proposed runtime change or novelty claim.
