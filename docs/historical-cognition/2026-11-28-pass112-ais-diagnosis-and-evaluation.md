## Original Ora crosswalk
An agent can infer faults in an unfamiliar instance of a process using a model supplied beforehand; this is not evidence it discovered the model. Larsson's explicit means-end representation separates domain structure from inference over that structure. Isbister and Doyle's evaluation taxonomy provides a complementary caution: convincing behaviour, application success and computational autonomy require different measurements. Ora's reported inherited functional variation therefore does not establish a discovered causal model, learning or broad intelligence. Diagnostic success would have to be distinguished from pre-existing environmental semantics or an inherited fixed policy, with independent evidence of acquisition and transfer. This is historical research interpretation only, not an authorized engineering test.
